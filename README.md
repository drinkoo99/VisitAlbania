# VisitAlbania

## Project Description
**VisitAlbania** is an interactive and modern website that promotes tourism in Albania. It features various sections showcasing top destinations, attractive images, and options for users to explore the country's main tourist attractions.

## Technologies Used
- **HTML**
- **CSS**
- **JavaScript**
- **Bootstrap**

## Key Features
- **Fully responsive navbar** that adapts to all screen sizes
- **Hero Section** with images that change automatically with delay and zoom-out effect
- **Destinations Section** showcasing key tourist locations (partially completed)
- **Full responsiveness** for mobile, tablet, and desktop devices
- Smooth animations and visual effects to enhance user interaction
