# VisitAlbania

VisitAlbania is a simple tourism website that presents Albania’s destinations, culture, food, and events.  
The project is focused on providing basic information about Albania in a clean and responsive way.

---

## Technologies Used

- HTML
- CSS
- JavaScript
- Bootstrap
- React

---

## Features

- Multi-language support (implemented with JavaScript)
- Responsive design (works on desktop and mobile)
- Lazy loading for images
- Clean and simple UI

---

## Website Sections

- Home  
- Destinations  
- Activities  
- Food & Culture  
- Events  
- About Us  
- Contact  
- Languages
